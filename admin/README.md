# Loom for Women — Admin

Trang quản trị. Chạy ở port **3011**.

## Stack
- Vite + React 18
- Tailwind CSS (primary palette)
- React Router DOM
- Zustand (state)
- Recharts (biểu đồ)
- Framer Motion (animation)

## Cài đặt
```bash
cd admin
npm install
npm run dev
```

Mở http://localhost:3011

## Deploy (Vercel)
Sẵn sàng deploy — xem `vercel.json` ở thư mục này (đã cấu hình SPA rewrite chống 404).
